### System Search
* **`Alt + Space`** or **`Alt + F2`** : Open KRunner (Quick Search & Run)
* **`Meta`** (Super/Windows Key) : Open Application Launcher


### Desktop Navigation
* **`Meta + F12`** : Toggle Show Desktop
* **`Ctrl + F1`** to **`F4`** : Switch to a specific Virtual Desktop


### Moving Windows Between Desktops
* **`Meta + Ctrl + Left / Right`** : Switch to next/previous Virtual Desktop
* **`Meta + Shift + Up / Down`** : Move active window to next/previous desktop
